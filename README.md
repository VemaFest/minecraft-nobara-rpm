# minecraft-nobara-rpm
This package downloads the official Minecraft launcher file directly from this link:

https://launcher.mojang.com/download/Minecraft.tar.gz

which can be found in the link for other Linux distributions on the official website:

https://launcher.mojang.com/download

Download the file:

minecraft-nobara-rpm-0.3-1.fc43.noarch.rpm

and run the command:

sudo dnf install minecraft-nobara-rpm-0.3-1.fc43.noarch.rpm

NOTE:
The file “Instalar_mc” is the script that allows you to perform the entire installation.
